# source-command-peca-juridica

Use this skill when the user asks to run the migrated source command `peca-juridica`.

## Command Template

# Peça Jurídica Visual

Monta documentos jurídicos no formato visual, cards com ícone, cabeçalho com foto, caixas de destaque para valor e prazo, em vez de texto corrido tradicional. Cobre três tipos: a peça principal do caso (que pode ela mesma ser um contrato), procuração e contrato de honorários. Pode gerar um, dois ou os três juntos.

## Usage

```
/peca-juridica
```

Siga a skill `peca-juridica` para o fluxo completo, o design system e o checklist de conteúdo.

**Fora de escopo:** modelo tradicional em Word/ABNT para juntar em processo físico ou PJe. Se for isso que o Felipe quer, confirme antes, esse comando é só para o formato visual.
